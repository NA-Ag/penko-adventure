Getting Started: Let's create your content pack! Start by giving it a title and description. This helps players understand what kind of adventure they're about to experience.

Pack Metadata

Create Locations: Every adventure needs places to explore! Add at least one starting location where the player begins their journey.

Location Creator

Coming soon: Visual location builder with drag-and-drop connections!

Location Structure (Reference)

{
  "id": "forest_clearing",
  "name": {
    "es": "Claro del Bosque",
    "en": "Forest Clearing"
  },
  "description": {
    "es": "Un hermoso claro...",
    "en": "A beautiful clearing..."
  },
  "connections": {
    "norte": "ancient_temple",
    "sur": "village_market"
  },
  "npcs": ["forest_guardian"],
  "items": ["health_potion"]
}

Add Objects: Objects make your world interactive! Players can examine, take, use, and combine objects to solve puzzles and progress through your adventure.

Object Creator

Coming soon: Visual object property editor based on World Forge!

Object Structure (Reference)

{
  "id": "ancient_key",
  "name": {
    "es": "llave antigua",
    "en": "ancient key"
  },
  "description": {
    "es": "Una llave de bronce antigua...",
    "en": "An ancient bronze key..."
  },
  "properties": {
    "is_takeable": true,
    "is_container": false,
    "is_locked": false,
    "unlocks": ["temple_door"]
  }
}

Create NPCs: Non-player characters bring your world to life! They can give quests, provide hints, or engage in conversations with the player.

NPC Creator

Coming soon: Visual NPC dialogue builder!

NPC Structure (Reference)

{
  "id": "forest_guardian",
  "name": {
    "es": "Guardián del Bosque",
    "en": "Forest Guardian"
  },
  "description": {
    "es": "Un anciano sabio vestido de verde...",
    "en": "A wise old man dressed in green..."
  },
  "dialogue": {
    "greeting": {
      "es": "Bienvenido, viajero...",
      "en": "Welcome, traveler..."
    }
  }
}
